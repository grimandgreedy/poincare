# poincare-lib

`poincare-lib` is the reusable plotting layer in the Poincare workspace, built around [`viewport-lib`](https://github.com/grimandgreedy/viewport-lib). It provides plot types, expression parsing, scene construction, and style/domain controls for 3D mathematical and scientific visualization.

- Builds scene data for rendering through [`viewport-lib`](https://github.com/grimandgreedy/viewport-lib).
- Supports surfaces, curves, point clouds, vector fields, volumes, isosurfaces, and streamlines.
- Accepts both built-in plot types and expression-driven plot definitions.
